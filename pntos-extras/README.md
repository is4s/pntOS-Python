# PntOS-Python Extras

A set of auxiliary pntOS-Python plugins and tools to build on those in Cobra.

Plugins in this package are not included in Cobra for one or more of the following reasons:

1. They are more advanced than plugins in Cobra
1. They are somewhat experimental
1. They serve a more niche purpose
1. They do not conform to the same typing and error-checking standards as Cobra plugins.
